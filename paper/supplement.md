# Supplement

## 1. System description

| Component | Implementation |
|---|---|
| Hosting | Static files on GitHub Pages; no application server, no database |
| Code | Approximately 3400 lines of JavaScript (ES modules), HTML, CSS; no third-party runtime dependency, no build step |
| DICOM parsing | Implicit/Explicit VR Little Endian, Explicit VR Big Endian, Deflated Explicit VR; nested sequences; encapsulated pixel data |
| Pixel decoding | Native 8/16/32 bit, RLE Lossless, JPEG Lossless (Process 14), baseline JPEG (browser decoder), palette color, RGB/YBR_FULL |
| Archive | Unmodified DICOM Part 10 objects (gzip transport) with a JSON index created by an ingestion tool; local import into browser storage |
| Access control | Per-account envelope, PBKDF2-SHA-256 (310 000 iterations) and AES-256-GCM |
| Result storage | Browser storage; optional upload of reports and evaluations to a private repository through the GitHub API |

Verification: header values and decoded pixels were compared with pydicom on 61 objects (demo
series and pydicom test files; six transfer syntaxes). Fifty-eight were bit-identical. Differences:
one palette-color object (converted to RGB by design), one uncompressed YBR 4:2:2 object (not
supported), one odd-sized big-endian RGB object.

## 3. Evaluation instrument

**Tasks (13).** Worklist search; scrolling and cine; windowing; zoom/pan/rotate; length and angle;
ROI and point attenuation; multiplanar reformation and MIP; prior comparison with synchronized
scrolling; multi-series MRI with reference lines; radiograph; key image, annotation, export;
reporting; DICOM attributes. Full wording (German and English): `pacs/js/protocol.js`.

Per task: completion (without problems / with difficulty / not possible); rating compared with the
reader's clinical PACS (1 much worse – 5 much better); optional comment.

**System Usability Scale.** Ten items, five-point agreement; score = 2.5 × Σ (odd items: answer − 1;
even items: 5 − answer). The German wording used in the app should be checked against the
validated translation the authors intend to cite.

**Overall items (five-point agreement).** Image quality adequate for diagnostic viewing; loading and
response times acceptable; feature set covers core PACS functions; ran reliably; would use for
teaching or research; could imagine clinical use given regulatory clearance. Plus one global
comparison with the clinical PACS and three free-text fields (missing functions, errors, comments).

**Automatically recorded.** Feature use counts, series load times, browser and screen size.
